Each page is an **isolate profile**: bindings, routes, secrets, and behavior for one worker in the mesh.

Worker sources live as **git submodules** under `workers/` in [hoox-sh/hoox](https://github.com/hoox-sh/hoox). Each repository carries a GitHub description, `package.json` description, and a README with a shared **Mesh interconnect** section that links every sibling isolate.

## Ingress & execution

| Worker | Role | Source |
| ------ | ---- | ------ |
| [hoox (Gateway)](hoox) | Public webhook ingress, WAF/auth, Durable Object idempotency, queue/service dispatch | [hoox-worker](https://github.com/hoox-sh/hoox-worker) |
| [trade-worker](trade-worker) | Exchange REST execution (Binance / Bybit / MEXC), test trading, D1 fills | [trade-worker](https://github.com/hoox-sh/trade-worker) |
| [web3-wallet-worker](web3-wallet-worker) | On-chain wallet identity (ethers.js); bridge toward DeFi settlement | [web3-wallet-worker](https://github.com/hoox-sh/web3-wallet-worker) |
